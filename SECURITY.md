# Security policy

This preview is not yet supported for production security-sensitive workflows. Report suspected vulnerabilities privately to repository maintainers through GitHub private vulnerability reporting once the repository is hosted. Do not post sensitive files or secrets in public issues. There is no hosted project/contact configured in this workspace yet.

Document resource loading is blocked, processes receive argument lists, and AI/network services are absent. Keep your system Qt and Git updated. Dependency distribution terms are in THIRD_PARTY.md.
