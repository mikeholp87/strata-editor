# Feature status (0.1.2 preview)

Implemented: new/open/multiple open/save/save-as/save-all/close/reopen/recent, reload, drag/drop, print/preview, text and HTML modes, Markdown Source/Split/Preview modes with session persistence, HTML/PDF export; tabs, side-by-side/stacked shared splits; line numbers, current line, auto-indent, pairing, line duplication, comments, indentation, selection case conversion, whitespace trimming, LF/CRLF conversion, go to line/column, font/wrap preferences; basic language detection and lexical highlighting for all initial requested languages; project tree and hidden files, loaded-tree quick open, fuzzy command palette; case/whole-word/regex find/replace; bounded cancellable project literal search; Git status/branch/diff/stage/unstage/commit/history through asynchronous QProcess; external terminal; settings, dock layouts and session/recovery persistence; searchable command shortcut editor with recording, clear/reset, conflict checks and JSON import/export.

Autocomplete: a popup suggests words (3+ characters) from the current document plus keywords for C/C++, Rust, Python, JavaScript/TypeScript, Bash, SQL, CSS and HTML. It opens while typing or with Ctrl+Space; Tab/Enter accepts and Esc dismisses. It scans 128 KiB of text on each side of the cursor, so very large files stay responsive. It is lexical, not language-server aware.

Markdown source formatting: Edit → Markdown and the Markdown toolbar toggle bold, italic, strike, inline code, headings, bulleted/numbered/task lists, quotes, links and fenced code blocks, per selected line. Enter continues lists and quotes outside code fences; an empty item ends the list.

Rich formatting: bold, italic, underline, strike, paragraph/headings, font family/size, foreground/background, bullets/numbering, alignment, links, rules, tables. User content cannot load external images or remote resources. Rich paste through the application shortcut is plain text; Qt HTML import supports its own safe subset without script execution.

Limits: quick open sees currently loaded QFileSystemModel entries, not an indexed project. Project search skips >2 MiB and NUL-containing files; excludes .git/node_modules/build but does not yet parse ignore files. Maximum 1,000 matches. Regex replacement inserts literal text; capture expansion and search-in-selection are not supported. No multi-file replacement. HTML is a visual document mode, not a lossless HTML source editor. Markdown raw HTML is disabled; Qt GitHub dialect is used without a separate CommonMark conformance suite. Preview-only mode is implemented; linked scrolling and TOC are planned. U+2029 source files are explicitly refused because Qt uses that character for paragraph boundaries. Recovery snapshots are limited to 64 MiB total with failure warnings and previous-snapshot retention. One process owns the workspace data at a time. Character count is UTF-16 units, as are cursor columns; reading estimate assumes 200 words/minute.

No DOCX/RTF claims, image embedding UI, spelling/dictionaries, typewriter scrolling, multi-cursor, column selection, folding, line moves, smart Home/End customization, pin tabs, movable split tabs, extension loading, AI integration, LSP or Tree-sitter. Tree file mutation UI is deferred. Source documents saved to .md remain source documents in the current session; use New Markdown for live preview immediately. Reload uses a bounded synchronous read; decode on ordinary open/session restore uses workers. Saves, layout and serialization still run on the UI thread within the 8 MiB cap. Not yet performance-certified.

Shortcut customization applies to registered application commands. Changes stay in a dialog draft until Save. Invalid, duplicate or prefix-conflicting mappings are rejected. Native text navigation and widget context-menu bindings are not globally remapped; a registered command assigned to one of those keys takes precedence in the source/rich editor. Operating-system global shortcuts and menu mnemonics are outside the conflict check.

Usability: independent saved project-sidebar font size; Ctrl++/Ctrl+- for the focused source editor or project sidebar; individual split-view X buttons that preserve the shared document; a visible focus-mode exit with restored panel state; closing the last tab leaves an editable empty document.
